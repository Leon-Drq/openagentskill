# Support

Choose the channel that best matches your request.

| Request | Channel |
| --- | --- |
| Product or API bug | [Bug report](https://github.com/Leon-Drq/openagentskill/issues/new?template=bug.yml) |
| Feature proposal | [Feature request](https://github.com/Leon-Drq/openagentskill/issues/new?template=feature.yml) |
| Submit or correct a Skill | [Skill submission](https://github.com/Leon-Drq/openagentskill/issues/new?template=skill.yml) or [web submission](https://www.openagentskill.com/submit) |
| Usage question or integration discussion | [GitHub Discussions](https://github.com/Leon-Drq/openagentskill/discussions) |
| Security vulnerability | GitHub private vulnerability reporting; see [SECURITY.md](./SECURITY.md) |
| Conduct concern or private contact | [qudongqi2023@gmail.com](mailto:qudongqi2023@gmail.com) |

## Before opening an issue

1. Search existing issues and Discussions.
2. Include a reproducible URL, task, Skill slug, or API request when applicable.
3. Remove secrets, access tokens, private repository data, and personal information.
4. For production incidents, include the approximate time and timezone.

## Response expectations

OpenAgentSkill is currently maintained as an open-source project rather than a paid support service. Maintainers prioritize security reports, production regressions, data integrity, and reproducible bugs. Response and resolution times are best effort.

Third-party Skills remain the responsibility of their maintainers. OpenAgentSkill can correct registry metadata or flag risk, but cannot provide support for code it does not maintain.
